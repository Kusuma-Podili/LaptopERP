# LaptopERP REST API Reference

All endpoints are hosted under `/api/v1/` and require Token or Session Authentication.

## Endpoints Summary:
- `GET /api/v1/users/`: List users and roles.
- `GET /api/v1/models/`: List and filter laptop models.
- `GET /api/v1/units/`: List serialized units by status and condition grade.
- `GET /api/v1/warehouses/`: List warehouse facilities and capacities.
- `GET /api/v1/suppliers/`: Supplier directory.
- `GET /api/v1/purchase-orders/`: Purchase orders and line items.
- `GET /api/v1/job-cards/`: Workshop repair job cards.
- `GET /api/v1/customers/`: Customer CRM database.
- `GET /api/v1/sales-orders/`: Sales orders and statuses.
- `GET /api/v1/invoices/`: Invoices and payment status.
- `GET /api/v1/rma-tickets/`: Warranty and RMA claims.
