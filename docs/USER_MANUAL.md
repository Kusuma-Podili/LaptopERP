# LaptopERP User Manual & Operator Guide

## 1. Inward Receiving & Quality Check
1. Go to **Procurement** -> **Purchase Orders**.
2. When physical goods arrive, generate a **Goods Receipt Note (GRN)**.
3. Run the **Inward Quality Check (IQC)**.
4. Units passing IQC receive unique Serial Number barcodes and move to **In Stock**.

## 2. Workshop Repairs & Diagnostics
1. When a unit is submitted for maintenance, a **Job Card** is created.
2. The technician executes the diagnostic checklist.
3. Spare parts are requisitioned from inventory.
4. On repair sign-off, the unit transitions back to **In Stock** or **Ready for Dispatch**.
